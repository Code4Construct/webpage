kojiPDFviewer

kojiPDFviewer は試験的に作成中です。v0.1.0 の配布ファイルは GitHub Releases からダウンロードできます。

GitHub Releases でダウンロード

ダウンロード方法

  1. 上のボタンから v0.1.0 の GitHub Releases ページを開きます。
  2. 「Assets」を開き、使用する配布ファイルを選んでダウンロードしてください。
  3. ダウンロード後、リリースページに検査情報やハッシュ値が掲載されている場合は確認してください。

ウイルスチェックと確認情報

配布ファイルについてはウイルスチェックが行われています。検査対象のファイル、検査日時、検出状況など、公開されている検査情報をご確認ください。

GitHub Releases の配布元と、公開されている SHA256 などの照合情報がある場合は、ダウンロードしたファイルとの一致も確認できます。ウイルスチェックの結果は検査時点の情報であり、安全性を完全に保証するものではありません。

新しい Windows アプリでは、ダウンロード時や実行時に SmartScreen 等の警告が表示される場合があります。配布元と検査情報を確認したうえで、ご自身で利用を判断してください。
